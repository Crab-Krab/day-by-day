DAY BY DAY

Open Day-by-Day.html in Chrome, Edge, Firefox, or another modern browser.
The downloaded file works without an internet connection or account.

Use the sun/moon button beside Add task to switch between light and dark.
The first visit follows your system theme. Your choice is remembered in this browser.
Weekday names follow the browser locale; weeks still start Monday.

Day and view headings and the task window use short, subtle fades. The clickable
checklist and its task rows do not move or fade, as a precaution for an intermittent
Edge issue where the checklist stopped responding until a window repaint.
Enable Reduce motion in your device's accessibility settings to turn effects off.

The app opens to today's list. Choose a weekday or a date on the month calendar
to see another day. On a small screen, use the Calendar button to show the month.

Use + Add task to enter a task, date, and One time or Every week.
For weekly tasks, select any combination of weekdays under Repeat on.
Mon-Fri selects the five weekdays; Every day selects all seven days.
One task can repeat on multiple days and is edited as a single routine.
Weekly routines begin on their Starting on date. Each scheduled date gets its
own checkbox. Completing one occurrence does not check off other occurrences.
Existing single-day tasks and older backups keep their schedules and history.
Existing tasks remain All day until you assign a specific time.
Overdue appears above the checklist on today's page. Unfinished timed tasks,
including routines, move there once today's due time has passed. The app checks
every 30 seconds while open and catches up when you return to the tab. Today's
all-day tasks stay in the checklist. Tasks appear in one section at a time;
today's completion progress includes those in Overdue.
Unfinished one-time tasks from earlier dates also appear in Overdue. Completing
one there records completion on its original date. Move to today explicitly
changes its date. Missed recurring occurrences from earlier dates are not carried
into this section. Today's overdue routines can still be skipped or rearranged.

Use the pencil next to a task to edit it. One-time tasks can be deleted. For a
routine, select Apply changes / end routine from (today or later). Save changes
apply from that date onward and replace later planned edits. Earlier days and
completed occurrences keep their saved details, including name, notes, and time.
End routine stops new occurrences starting on the chosen date and keeps the
routine in Ended routines. View history opens its most recent scheduled date.
Ended routine details are read-only. To convert a one-time task, edit it, select
Every week, and choose its weekdays. Repeats begin on the chosen starting date
or today, whichever is later. Earlier or completed original occurrences keep
their details; future repeats start unchecked. Undo restores the one-time task.
To change a weekly routine into a one-time task, create a separate one-time
task and end the routine to preserve its history.
Skip this occurrence hides one incomplete occurrence today or in the future.
Restore occurrence brings it back from Skipped for this date. Other repeats
are unchanged. Undo is available above the checklist without a countdown, until
the next data change, dismissal, or closing/reloading this tab.

Add an optional Description when creating or editing a task. Use it for details,
multiline notes, and web links (starting with https:// or http://), up to 5,000
characters. Descriptions appear directly below each task. Longer notes show a
preview of up to three lines / 240 characters, with Show more and Show less to
expand or collapse them. The arrows and checkbox stay at the top of that task.
Web links open in a new tab. Descriptions are shared across a routine's scheduled days, saved in
this browser, and included in backups. Clear the Description field to remove it.
Older tasks and backups load with empty descriptions.

Tasks default to due-time order, earliest first, with All day tasks at the end.
Tasks with the same time sort alphabetically by name, ignoring capitalization;
the All day group also sorts alphabetically. Numbered titles use natural order
(Task 2 before Task 10). Custom ordering takes precedence over these defaults.
Use the small up/down arrows beside the checkbox to move any task in its section,
regardless of due time. The first move switches to custom ordering, starting from
the current due-time order. The custom order is saved for that weekday and reused
in future weeks; other weekdays are unchanged. New tasks follow ranked tasks in
due-time order. Sort by due time resets only the selected weekday. The Weekly
routines catalog has a separate order that never changes daily orders. Completed
tasks stay in their own section in both ordering modes. Older shared preferences
are migrated into all seven weekday preferences, which can then be changed
independently. Ordering preferences and routine history are included in backups.

TASK TIMES AND REMINDERS
Choose All day for no due time, or Specific time to set a due time.
For timed tasks, choose any combination of 5, 15, 30, or 60 minutes before due.
Leave every reminder interval unchecked for a timed task with no reminder.
Weekly tasks use the same local time and reminder settings on each selected day.

Keep this HTML file open in your browser for reminders. No alert can run after
the file/tab is closed or while the computer is asleep. Browsers can suspend or
slow background tabs, so reminder timing is not guaranteed in the background.
When the app resumes or reopens, missed reminders for tasks due within the last
24 hours appear in the reminder panel. Multiple missed intervals are combined.
Completed tasks do not generate reminders. The bell opens active reminders;
you can dismiss a reminder or jump to that task's day. Later selected intervals
can remind you again. Reminder history is kept locally to prevent duplicates
after reloading; backups contain task settings but not the alert history.
New tasks or changed schedules already past their due time do not trigger old
reminders immediately. Existing-task catch-up remains available. Supported tabs
use Web Locks to coordinate delivery; unsupported browsers fall back to best effort.

Desktop alerts are optional. Use Enable desktop alerts inside the timed-task
form to request permission. Some browsers or work policies refuse desktop alerts
for local files. In-app reminders still work, and the tab title shows a count.
All dates and times use the computer's local timezone.

Tasks and completion history save automatically in the current browser.
Use the same browser and the same file location or web address each time.
Browsers keep separate copies. The hosted app and downloaded HTML also keep
separate copies. A private/incognito window will not keep your tasks after closing.
Clearing browser data can erase saved tasks. Browser support for saving from a
local file can vary; the app shows a warning if saving fails.

Use Back up tasks to download a backup, and Restore backup to move that copy
between browsers or between the hosted and downloaded versions. Restore replaces
the current tasks and completion history, so make a backup first if needed.
Last backup exported records when a download was initiated; check that it saved.
A gentle backup notice appears after 25 changes or a week with unexported changes.
Remind me tomorrow postpones that notice for a day. Backup status stays in this
browser and is separate from exported tasks. Storage protection can be requested
where supported; it does not replace backups or prevent deliberate data clearing.

The one-time task form uses one Date input. The single-letter N shortcut has been
removed to avoid accidental activation. Use the Add task button with mouse or keyboard.

The app uses your device's local date. If it stays open overnight, it updates
to the new day automatically when you were viewing today.

This build writes data/backup format 5 and accepts older formats 1 through 5.
Back up before updating. Use this updated HTML to read format-5 backups; older
HTML versions cannot read them. History already removed by an older version
cannot be reconstructed.
