A documentation fix for v1.7.0. **The app itself is unchanged**: Day-by-Day.html is byte-for-byte the same as in v1.7.0, so there's no need to replace your copy.

## What's fixed

- **The right button name in the guides.** Until a task file is connected, the saving row's button reads **Set up task file**. It's called **Manage** only after a file is connected. The included **Read-me.txt** and **File-autosave-guide.md** said to choose **Manage** in both cases. They now name the button you actually see.
- **Coming up is described.** The README now explains **Coming up**: beside the checklist on wide screens, and below it, behind **Show**, on smaller ones. It also notes that the reorder arrows sit below each task on phones.

## Download and update

If you already use v1.7.0, nothing to do. From an earlier version, back up tasks and wait for any file save to finish, then close the old app tab. Download **Day-by-Day.html** from Assets, replace your working HTML, and reopen it in the same browser and location. Your connected task file keeps working.

Saved-data format remains 5, so v1.4.x through v1.7.1 can read each other's tasks and backups.

## Validation

All automated suites passed, and GitHub runs them on Node 22 and 24. The release workflow ran the Chrome browser checks before publishing. The corrected instructions were checked against the app's button labels with and without a connected task file.
