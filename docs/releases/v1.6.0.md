A roomier, calmer layout: a Coming up column on wide screens, a compact saving panel, quicker task entry, and tidier task rows.

## New in v1.6.0

- **Coming up (wide screens).** On screens 1360 pixels wide and up, the checklist uses the whole width beside the sidebar, and a Coming up column lists the next 7 days with each day's task count and up to six task names. Select a day to open it. Narrower screens and phones keep the familiar layout.
- **Compact saving panel.** Once your task file is connected, saving shrinks to one line. **Manage** shows file controls, browser saving, and backups together, and problems open it automatically.
- **Quicker task entry.** A new one-time task starts with just a name and a date. **More options** reveals notes, repeats, time, and reminders. Editing a task and adding a routine still open the full form.
- **Tidier task rows.** The reorder arrows stay beside each task. **More** holds Skip and reminder details, and appears only when a task has them. A small bell beside the time shows which tasks have reminders. Overdue tasks keep **Move to today** and **Move to tomorrow** visible.
- **Collapsible Completed section.** Hide finished tasks for a day while keeping the count and progress visible.
- **Click outside to close.** Clicking outside the task window closes it, like Cancel. If you've typed or changed anything, the app asks before discarding it.
- **Easier to tap.** Bigger click areas around checkboxes, with tighter spacing elsewhere.

## Fixes

- **No surprises while reconnecting.** If you're editing a task while the app reconnects your task file at startup, it waits until you save or cancel, then asks which copy to keep if they differ.
- **Save never looks stuck.** If a hidden field needs fixing, the extra options open so the browser can point to it.
- **Edge click problem.** The task window now closes instantly, and the checklist stays usable during startup reconnection. Both address possible causes of the intermittent Edge issue, but a lasting fix isn't confirmed yet.

## Download and update

Back up tasks and wait for any file save to finish, then close the old app tab. Download **Day-by-Day.html** from Assets, replace your working HTML, and reopen it in the same browser and location. Reconnect your existing JSON task file with **Open task file** if needed.

The app is still one self-contained HTML file with nothing to install, and it never contacts the internet. Saved-data format remains 5, so v1.4.x, v1.5.0, and v1.6.0 can read each other's tasks and backups.
