# Day by Day v1.2.0

Overdue tracking, independent weekday ordering, history-preserving routines, and improvements to everyday use.

## Download and update

1. **Back up your tasks in your current copy before updating.**
2. Under **Assets**, download **Day-by-Day.html**. The optional **Read-me.txt** contains usage instructions.
3. Replace your working HTML and open it in the same browser and file location. Restore your exported backup if needed.

The app remains one self-contained HTML file. No installation, account, server, or internet connection is needed to use it.

**Data compatibility:** This release accepts saved data/backups in formats 1–5 and writes format 5. Older app versions cannot read format 5. History already removed by earlier versions cannot be reconstructed.

## New and improved

- **Overdue above the checklist:** Unfinished timed tasks, including routines, move there after today's due time. Earlier unfinished one-time tasks also appear there, with completion on their original date or **Move to today**. Today's all-day tasks stay in the checklist. Lists update automatically as time passes, with no duplicate task entries or inflated counts.
- **Independent weekday ordering:** Rearranging Monday applies to future Mondays and leaves other weekdays alone. The routine catalog has its own order. Older shared custom orders are migrated without losing their starting order.
- **Routine history:** Choose when routine edits take effect. Earlier definitions and completed occurrences retain their details. **End routine** preserves history, and **Skip this occurrence** / **Restore occurrence** affect one date. Ended routines remain available to view.
- **One-time to weekly conversion:** Select **Every week** when editing a one-time task, choose multiple weekdays, and keep earlier/completed original occurrences. Conversion includes Undo.
- **10-second action confirmations:** Confirmations and Undo banners dismiss automatically, pausing while hovered, keyboard-focused, or the tab is hidden. Task reminders have no confirmation-style timeout.
- **Backup help:** See the last backup export date, receive gentle backup notices, and request browser storage protection where supported. Browser storage protection is optional and does not replace backups.
- **Accessibility and polish:** Improved dialog focus restoration, stable completion-toggle labels, status announcements, calendar contrast, system fonts, localized weekday names, system theme on first visit, and a simpler one-time Date field. Removed the single-letter N shortcut.
- **Layout refinements:** Aligned sidebar counts and calendar labels, moved **Add a task to this day** into the checklist header, and filled the **Back to today** button.
- **Reminder reliability:** Newly entered past-due tasks avoid immediate catch-up alerts; supported browsers coordinate alerts across tabs. Calendar task counts avoid unnecessary sorting.

Reminders remain best effort: keep the file open and the computer awake. Sleeping or suspended tabs can delay them. Missed recurring occurrences from earlier dates are not carried into Overdue.
