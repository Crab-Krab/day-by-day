Task descriptions, flexible sorting, and improvements to everyday use.

## Download and update
1. Back up your tasks in your current copy.
2. Under Assets, download **Day-by-Day.html**.
3. Replace your working file and open it in the same browser and file location. Restore your backup if needed.

The app remains one self-contained HTML file: no installation, account, server, or internet connection is needed to use it.

## New and improved
- Optional descriptions for task details, multiline notes, and clickable web links, included in local saving and backups.
- Descriptions appear directly beneath tasks, with Show more / Show less for longer notes.
- Arrows, checkboxes, and Edit stay anchored at the top when notes expand.
- Browser-tab icon matching the green checkmark branding.
- Default sorting by earliest due time, with alphabetical ordering for equal times and all-day tasks last.
- Unrestricted custom ordering using the up/down arrows. Custom order is saved and backed up; Sort by due time restores automatic sorting.

## Edge checklist workaround
An intermittent issue made the entire checklist stop accepting clicks or keyboard focus until resizing the window or opening Add task. This release removes animations and clipping around the interactive checklist, retains heading/dialog fades, and cleans up finished animation effects. **The cause and long-term resolution are not yet confirmed.**

## Validation
JavaScript syntax and automated scheduling, reminder, migration, description/link, preview, ordering, persistence, and animation runtime checks passed. These checks do not establish local-file visual behavior in every browser.
