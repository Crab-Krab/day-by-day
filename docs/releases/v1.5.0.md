Optional recovery copies, one-click save retries, keyboard-friendly calendar navigation, and links between moved tasks and their original day.

## New in v1.5.0

- **Recovery copies (optional, desktop Chrome and Edge).** Choose a folder, and the app keeps up to 20 earlier versions of your tasks there. A copy is saved at most once an hour while you work, and right before deleting a task, ending a routine, restoring, or choosing which copy to keep. **Show copies** lists them by local date and time. **Restore** asks first and saves your current tasks as a copy before replacing them. Copies never stop your tasks from saving: if the folder can't be used, copies pause and saving carries on. The app only ever removes its own copy files.
- **Retry buttons.** When the browser can't save, **Retry saving** tries again right away without another edit. When saving to your task file fails, **Retry file save** tries again, but only if nothing else changed the file. Otherwise **Reconnect task file** still asks which copy to keep.
- **Calendar keyboard and Go to date.** The arrow keys move between days on the month calendar, into the next or previous month and year. Tab always reaches one day of the calendar. **Go to date** below the calendar opens any date you type.
- **Moved task links.** A task carried over by **Move to tomorrow** shows **Moved from** as a link back to its original day, and that day shows a matching **Moved to** link.

## Download and update

Back up tasks and wait for any file save to finish, then close the old app tab. Download **Day-by-Day.html** from Assets, replace your working HTML, and reopen it in the same browser and location. Reconnect your existing JSON task file with **Open task file** if needed.

Saved-data format remains 5. v1.4.x and v1.5.0 can read each other's tasks and backups, and formats 1–5 can still be imported.
