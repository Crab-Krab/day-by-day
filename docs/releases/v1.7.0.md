Day by Day 1.7 refreshes how the app looks and is laid out. Your tasks, routines, history, reminders and saving work exactly as before.

## What's new

- **A calmer look.** Grey surfaces in light and dark mode, with violet for buttons, the selected day, and keyboard focus. Amber marks overdue tasks and red marks save problems. One clear font and text size scale throughout. The tab icon matches the logo in both themes.
- **A layout that fits your screen.**
  - On big monitors the workspace stops widening, so tasks no longer stretch into long, sparse rows.
  - On phones, each task's buttons sit on their own row under the task text, so long titles have room.
  - **Coming up** is now available on smaller screens too. Select **Show** below the checklist.
- **Clearer task editor.** **One time / Every week** and the **Repeat on** days are always visible. **More options** now holds notes, time and reminders. If something needs fixing, the message appears under that field.
- **A quieter saving panel.** Saving is one line: **Saved to** your file with a check, or **Browser saving only** with a **Set up task file** link. **Manage** shows the task file, browser copy and backups, and recovery copies together. Problems still open the details automatically.
- **Easier to use with a keyboard or assistive technology.** A **Skip to main content** link, clearer labels for screen readers, support for Windows High Contrast mode, and buttons at least 44 pixels tall.

Decorative slogans are gone, apart from the footer line. See the changelog for the full list.

## What stays the same

Nothing about your data changes. Saved-data format remains 5, so v1.4.x through v1.7.0 can read each other's tasks and backups, and you can go back to v1.6.3 if you need to. The app is still one self-contained HTML file with nothing to install, and the browser enforces that it never connects to the internet.

## Download and update

Back up tasks and wait for any file save to finish, then close the old app tab. Download **Day-by-Day.html** from Assets, replace your working HTML, and reopen it in the same browser and location. Your connected task file keeps working.

## Validation

All automated suites passed, and GitHub runs them on Node 22 and 24. The interface browser tests passed in Chrome and Edge, with and without reduced motion, and the release workflow ran the Chrome browser checks before publishing. Layout was checked at 320, 375, 768, 1024, 1366, 1920 and 2560 pixels wide and at 200% zoom, with a 200-character title, a 5,000-character note, 40 completed tasks and 60 routines: no sideways scrolling, no clipped text, and the editor's buttons stayed reachable. The manual release checklist in `docs/TESTING.md`, including the new redesign checks and the Edge click check, was completed by hand during a working day of normal use.
