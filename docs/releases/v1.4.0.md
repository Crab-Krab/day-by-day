Move today's overdue tasks to tomorrow directly from the Overdue list.

## New in v1.4.0

- **Move to tomorrow:** Once an unfinished timed task becomes overdue today, its row offers this action. A task due at 6:30 can be moved at 7:00 to the next calendar day at 6:30.
- Keep the due time, notes, reminder settings, and an unchecked task tomorrow. Stay on today's page to continue through the list, with **Undo** available.
- For weekly routines, move only today's occurrence as a separate one-time task and skip the original date. Future repeats keep their existing schedule. If tomorrow already has a regular occurrence, both remain independently checkable.
- Earlier overdue one-time tasks retain **Move to today**. Completed, all-day, and not-yet-due tasks do not offer Move to tomorrow.
- Protect against stale repeated clicks, completed tasks, and midnight rollover. Calendar arithmetic handles month/year changes, leap day, and daylight-saving transitions.

## Download and update

Back up tasks and wait for any file save to finish, then close the old app tab. Download **Day-by-Day.html** from Assets, replace your working HTML, and reopen it in the same browser and location. Reconnect your existing JSON task file with **Open task file** if needed. Only the HTML needs to be opened; instructions, the MIT license, and checksums are included as reference downloads.

The app remains entirely local with no account, installation, server, or internet requirement. Direct JSON file autosave uses current desktop Chrome or Edge. After browser-data cleanup, you may need to select the existing JSON file again. Saved-data format remains 5, and formats 1–5 can still be imported.

## Validation

Automated scheduling, runtime, theme, history/migration, and file-persistence checks cover the new action, Undo, reload, reminder settings, recurring snapshots, separate future occurrences, date boundaries, and saving the move and Undo to JSON. Browser file-permission behavior remains dependent on browser support and workplace policies.

A local browser preview also verified moving an overdue task, Undo, keeping today's view open, and finding the unchecked task tomorrow with its time, notes, and reminders after reloading. No browser console errors were reported during that check.
