Automatic saving to a local JSON task file, so daily browser-data cleanup no longer removes the saved task file.

## Download and set up

1. Back up tasks in your current copy before updating.
2. Under **Assets**, download **Day-by-Day.html**. Only the HTML needs to be opened. **Read-me.txt** and **File-autosave-guide.md** provide instructions.
3. Open the HTML in current desktop **Chrome or Edge**.
4. Choose **Set up autosave** to create a permanent local JSON file from the tasks currently shown, or **Open task file** to use an existing task JSON/backup. Allow editing access.
5. Changes save automatically. Wait for **Saved to [filename]** before closing or signing out.

The app remains entirely local and requires no installation, account, server, or internet connection.

## New in v1.3.0

- Automatically save task additions, edits, completion, ordering, and deletions to the selected JSON file.
- Remember the file and reopen it automatically when the browser retains access. Use **Reconnect task file** when permission needs renewing.
- If browser cleanup erases the connection, choose **Open task file** and select the same JSON again. The JSON stays on disk; a standalone HTML file cannot silently rediscover it after the browser forgets permission.
- Show saving, saved, and error status. Serialize writes and warn before closing with pending changes.
- Detect external file changes and ask which copy to keep when file contents and pending browser edits differ. Invalid task files are not overwritten.
- Continue browser saving and manual JSON backup/restore in browsers that do not support direct file autosave.

Task data remains format 5. Existing format-1 through format-5 task backups are accepted. Keep occasional separate backups; autosave also saves deliberate deletions and restores.

## Validation

All five automated suites passed: scheduling, application runtime, theme, history/migration, and file persistence. File tests cover automatic reopening, browser cleanup/reconnect, expired permissions, blocked browser storage, queued edits, failed writes, conflicts, invalid JSON, and the actual task form/completion paths. The standalone build matches the committed HTML.

The actual Chrome/Edge file-permission flow was not verified in this environment; workplace browser policies may restrict file access.
