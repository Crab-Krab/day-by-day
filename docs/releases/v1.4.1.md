Bug fixes for saving, routine history, and reminders, plus a download link that always serves the latest release.

## Fixes

- **Browser saving recovers on its own.** After a save fails, the app tries again with every change and clears the warning once a save works. Closing the tab asks first while changes are not saved anywhere.
- **Another tab can't wipe unsaved changes.** If another tab saves while this tab has changes the browser could not save, the app asks which copy to keep.
- **The 10 MB limit is checked before a change is kept.** Task files and backups over 10 MB cannot be opened, so a change that would cross the limit is undone with an explanation. Deleting tasks is always allowed.
- **Skip works on every occurrence.** Skipping now hides an unchecked occurrence that kept saved details from an earlier edit. Days that older versions recorded as both done and skipped stay done.
- **Moved occurrences are labeled.** Tasks created by Move to tomorrow show "Moved from" and their original date. The original date shows where the task went, so Restore can't put it on both days.
- **No old alerts after reminder edits.** Adding a reminder to a task that is already overdue no longer sends an alert for the missed time. This includes routines with changes scheduled for later.
- **Disconnect always works.** If the browser cannot forget the task file, the app still disconnects for this visit and says the file may reopen next time.

## Download and update

Back up tasks and wait for any file save to finish, then close the old app tab. Download **Day-by-Day.html** from Assets, replace your working HTML, and reopen it in the same browser and location. Reconnect your existing JSON task file with **Open task file** if needed.

Saved-data format remains 5, and formats 1–5 can still be imported. Tasks moved to tomorrow gain an optional link to their original date, which older versions ignore.

## Validation

All five automated suites passed, including regression tests for each fix. GitHub Actions runs them on Node 22 and 24 and checks that the committed HTML and checksums match the source. A local Chromium check verified the new two-tab choice, keeping this tab's tasks, and the other tab updating afterward. Native file-permission prompts and the intermittent Edge issue were not tested.
