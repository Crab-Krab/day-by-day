## Download

Download **Day-by-Day.html** from Assets. Only the HTML needs to be opened. **LICENSE.txt**, **Read-me.txt**, and **File-autosave-guide.md** are reference files.

Back up tasks before replacing your working HTML, close the old app tab, then open the updated HTML in the same browser and location. Reconnect your existing JSON task file with **Open task file** if needed. Direct file autosave uses current desktop Chrome or Edge; after browser data cleanup, the app may need you to select the JSON again.
