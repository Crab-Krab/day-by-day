Day by Day browser checks

These checks use the real Day-by-Day.html in this browser, which the automated Node tests can't do. Start the preview with npm run preview and open this page from the address it prints. File pickers are turned off inside the test frames, so file permissions still use the manual checklist in docs/TESTING.md.

The checks only touch this test page's own storage, and they put back whatever was there before. Your everyday tasks are never used.
